# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation means keeping an object's information and functions together, it does this while limiting direct access to its data. In a sari-sari store inventory system, things such as a product's name, price, and stock can be stored in a class, while methods can be used to manage the stock

### 2. Abstraction
Your explanation here.
Abstraction means hiding all the unnecessary stuff and only showing the important parts. In a sari-sari store inventory system, we could simply use a function to add or update a product with ease and without having to understand how the system handles the information.

### 3. Inheritance
Inheritance means allowing a class to get the same properties and methods from another class. In a sari-sari store inventory system, a class can inherit basic information from a general class while having additional features that is for that specific type of item.

### 4. Polymorphism
Polymorphism means allowing the same class with the same method to work differently. In a sari-sari store inventory system, a method could be used for different types of products, but each of the products could show its information in a different way.
